# Ocean League Updates

Official Android APK releases and update information for Ocean League.

## Updates

The `latest.json` file provides the latest compatible Android release information.

New APK releases will be published through GitHub Releases.

## Installation

Install updates using the Ocean League app's built-in updater. Android will ask for approval before installing an update.

**Important:** Updates must use the same Android application ID and compatible signing key to preserve the existing installation and its local data.
